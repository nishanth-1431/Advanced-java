## Recommended completion order

The video outline introduces some topics before their prerequisites. For learning, follow `LEARNING-PLAN.md`: understand `pom.xml` and the project structure before going deeply into dependencies, repositories, and lifecycle commands.

## Scope notes

- **Required:** Maven fundamentals, Windows setup, first project, POM, dependencies, repositories, goals, lifecycle, testing, and Maven-based Spring Boot project.
- **Optional for now:** AWS EC2 setup and learning both IntelliJ and Eclipse. Use the IDE you actually work with first.
- **Comparison only:** Learn Gradle's purpose and key differences after you understand Maven; you do not need to master both build tools at once.

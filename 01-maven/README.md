# Maven

Hands-on notes and practical exercises for learning Apache Maven as part of my Advanced Java learning journey.

## Learning goals

- Understand what Maven does and why Java projects use it.
- Create and build a standard Maven project.
- Configure projects through `pom.xml`.
- Manage dependencies and repositories.
- Understand Maven goals, lifecycle phases, and plugins.
- Run automated tests and package applications.
- Understand how Maven is used in web and Spring Boot projects.
- Compare Maven with Gradle at a basic level.

## Module structure

| Folder | Focus |
|---|---|
| `basics/` | Introduction, installation, terminology, first project, goals |
| `project-structure/` | Standard layout, `pom.xml`, effective POM, web-app structure, IDE setup |
| `dependencies/` | Dependencies, scopes, transitive dependencies, repositories |
| `lifecycle/` | Lifecycle phases, goals, clean/build/package/install workflow |
| `plugins/` | Plugin basics and commonly used plugins |
| `practical-projects/` | Hands-on Maven projects and test cases |

## Study workflow

For every topic:

1. Learn the concept.
2. document it with explanations.
3. Try the related command or configuration.
4. Record the result and any errors.
5. Answer the review questions without looking at the notes.
6. Commit the completed work to Git.
